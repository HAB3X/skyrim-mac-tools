# Skyrim Together mod set

Both players need exactly this: Skyrim Together only connects players whose mods and load order match. These are the
mods from the Keizaal Online Nexus collection (revision 9) that work in co-op, without Keizaal's own
content. The Mac side runs them on GOG Skyrim 1.6.1179 with the Skyrim Together `mac` or `plus` build.

## Needed first
- **SKSE64** for your game version (skse.silverlock.org) and **Address Library for SKSE Plugins** (All in one).
- **Unofficial Skyrim Special Edition Patch** and **Alternate Start - Live Another Life**.
- Keep the free Creation Club content that comes with 1.6+ Skyrim (Fishing, Saints & Seducers, Rare Curios, Survival
  Mode) as it is.
- **Don't** install SSE Engine Fixes for Skyrim Together: players and NPCs turn invisible.

## The 45 files
Download each file from its link (Nexus Mods, "Manual download") and install it with Vortex, Mod Organizer 2 or by
hand into `Data`. On Steam 1.7.x, take the newest version of the SKSE plugins (Actor Limit Fix, SkyPatcher, MCM
Helper, powerofthree's Tweaks, Simple Dual Sheath, Crash Logger, Animation Queue Fix, Native EditorID Fix, Crafting
Categories) if the listed file doesn't support your version; everything else must be the exact file listed.

## Left out on purpose
- Keizaal's own content (Keizaal Online Patches and its server files): made for the Keizaal roleplay server.
- Nemesis: none of these mods need it.
- Skyrim Souls RE (unpaused menus): risky with co-op sync.
